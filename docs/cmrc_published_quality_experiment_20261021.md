# CMRC 实际发布单元的局部质量试验（2026-10-21）

本轮延续[上一轮真实源需求对照](cmrc_dual_area_stability_20261020.md)，修正私有试验的选点目标：从最终交付单元的尺度告警选择候选。生产 CMRC 没有启用该优化器，既有发布版本保持冻结。

## 准确的发布集合

上一轮完整区域最差尺度比从 2.0398 降至 2.0331，但最终发布网格没有变化。完整区域、原认证覆盖 R 和最终发布集合不能互换。

本轮读取已成功交付 control 的 `earthmesh_w_lineage`，它保存 pre-export parent 的 canonical W ID。ID `k>1` 对应按原生 active slot 顺序排列的闭合单元 `closed_sites[k−2]`；它不是 NetCDF 的物理行号，也不是原生 site slot。实际文件同时核对 canonical ID、经纬度位值（仅归一正负零）、唯一性、范围和 parent ID 的完整顺序。

已核对的 parent 闭合单元为 682,873，发布集合为 635,769，原认证覆盖 R 为 682,264。发布集合来自实际区域与 IGBP 陆地筛选后的最终文件，没有用 bbox 近似替代陆地筛选。lineage 文件绑定原始 fine／coarsened 网格指纹及单元数量，构网时重新校验；源数据和该文件的 SHA256 前后复核。

## 私有候选与验收

继续复用既有 dual 优化器，仅允许发布集合内的双端告警对进入候选。发布质量输入同时重编号单元、实际使用的顶点和子集邻居；完整区域的固定邻居和质量测量仍保留。使用既有全域及发布域 guarded 门禁，采用候选必须改善发布域最差相邻尺度比或减少告警对。既有质量策略不表示每一项原始数值都逐项下降。

原区域边缘、来源地址确定的二十面体锚点、原 R 及受影响邻域保护均保留；最多十点、总位移上限为当地边尺度 3%、最多四次回溯。原始 `SourceLevelField` 在重编号前认证，随后执行真实 Lattice 分支、fresh remap、几何与完整最终认证；候选拒绝时保留已完整认证的原结果。

静态集合本身不能证明移动后仍在相同区域或土地像素中。因此真实 CLI 交付后还逐个核对 canonical ID 集合与基线完全一致，检查实际发布质量确有改善，并做完整 NetCDF 差异比较。输入、二进制、选择文件及耗时／RSS 缺失或不一致都使验收失败。

全部重计算在 T7920 私有快照中运行，继续使用原生约 90 m MERIT；现有 `finest_m=90` 的实际最细名义尺度约 125.005 m。没有添加产品选项、默认优化器或新依赖。

同一私有 release 二进制顺序运行 control／trial，区域仍为东经 100–101.142°、北纬 38–38.901°，1 km 基准、高程标准差阈值 3 m、最少 4 个样本。两组输入及二进制 SHA256 前后保持一致，runner 终态为 `succeeded`，退出码 0，验收 `errors=[]`。

trial 首次有界候选实际采用 4 个非零位移，通过原始 **Lattice** 源需求、fresh remap、几何及完整最终认证。固定点坐标逐位不变，拓扑、原 R、报告及 epoch／retry 计数不变。两组均为 29 个组件提交、137 个保留 fine、0 个耗尽，搜索完成；两次普通候选失败均安全保留，单组件最多一次，没有 focused 重试。

原生三角形的最小／最大角为 38.20044°／81.79884°，仍满足 38.2°–81.8° 合同；发布多边形的角度是另一项度量。原认证覆盖 R 的 remap 证据通过，发布日志仍为 `certified_published_grid_remap_available=false`，不据此声称提供了对外发布的 remap 文件。

构网后重新读取两份实际 NetCDF：control 的 canonical ID 集合与选择文件完全一致，trial 与 control 的 635,769 个 ID 完全一致，已排除移动造成区域／陆地筛选成员变化的情况。最终网格与 `regional_parent` 的严格比较均仅发现 `GLATM`、`GLATW`、`GLONM`、`GLONW` 四个坐标变量值变化；类型、维度、属性、掩码、连接关系、层级和 lineage 等其他内容无差异。表中质量来自最终交付文件，而非优化器内部提议。

完整区域的 682,873 个闭合单元仍为最大相邻尺度比 **2.03982899→2.03982899**、告警 **4→4 对**；本轮改善出现在实际发布集合。优化器内部未限幅的提议曾显示完整区域 4→3 对，但采用后的 3% 有界候选并未减少告警，不能将提议报告当作交付结果。

本次单组顺序 A/B 总耗时增加 91.886 s（39.8%），峰值 RSS 增加 162,824 KiB（4.7%）；私有探针自身记录约 88.1 s。共享机器上的单次观测不足以建立统计性能基准，但已经显示额外成本。**实际发布质量有所改善，仍有 3 对尺度告警，综合质量结论仍为 `warn`。** 最大边长比、边长 CV 和跨层级面积 CV 的软告警也仍保留。
