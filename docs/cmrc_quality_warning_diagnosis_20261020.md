# CMRC 质量告警定位与真实 MERIT 复验（2026-10-20）

本轮接续技术指南 11.151，定位已验收网格的软告警，并补齐诊断导出。四组历史输出的指标复核一致；新增真实 MERIT 案例成功交付认证网格，但质量汇总仍为 `warn`。几何硬门禁通过不等于全部质量指标无告警。

## 1. 诊断修复的边界

- `quality_summary.json` 的每个 gate 增加已有的 `detail`，解释指标含义。过渡计数说明采用实际配置的阈值，修复此前始终写成 `> 2` 的问题。
- `worst_cells.geojson` 增加已有的 `center_lon`、`center_lat` 和可空的 `refine_level`。原有 `level` 继续表示质量判定，`cell_index` 继续表示质量输入索引。
- 明确 `aspect_ratio_max` 是单元最长边／最短边，`max_adjacent_resolution_ratio` 是相邻单元的面积平方根之比，`cell_area_cv` 是跨全部级别的面积变异系数。

没有调整指标计算、门槛、认证、构网算法或 AutoRefine 选点。新增字段沿用现有 JSON 转义和非有限数值转 `null` 的处理。GUI 的反序列化允许额外字段。

## 4. 用户选定的真实 90 m MERIT 案例

使用服务器已有 MERIT-Hydro（3 角秒，约 90 m），范围东经 100–101.142°、北纬 38–38.901°，约 100 km 区域。配置基础尺度 1 km、`finest_m=90`、高程标准差门槛 3 m、`minimum_samples=4`，Land／Hex／CoLM、Certified。没有使用新的 30 m DEM。

CLI 当前按最接近的二分尺度层级选择 `finest_m`（`CertifiedMergeOptions::levels`），不是严格的交付尺度上限。本例基础尺度 1000.040 m，选择 3 级，实际最细名义尺度 **125.005 m**；证书的 `levels_requested`、`finest_level_required`、`levels_built` 和交付最大级别均为 3。验收的 `requested_finest_band_exercised=false` 如实记录未达到 90 m，不能将本例称为实际交付 90 m。该离散层级策略本轮保持不变。

原始样本共读取 1,564,680 个。少于 4 个样本的面沿用现有规则：没有足够证据阻止合并，不承诺每个面均有足量高程样本。
