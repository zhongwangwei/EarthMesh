# CMRC 局部质量试验与可选更新回退（2026-10-20）

本轮接续[质量告警诊断](cmrc_quality_warning_diagnosis_20261020.md)，用四组历史交付网格的最差相邻尺度对做小范围试验，并定位现有可选坐标更新的退出漏洞。局部几何试验不等于通过实际构网的完整验收。

## 1. 原生坐标试验的结果和范围

重新核对全部 96 对告警：每对两端名义级别相同，分别为五边形与七边形。四份原始网格 SHA256 与上一轮冻结记录一致；本轮读取已有输出，没有新建 30 m DEM 案例。

每例提取最差的一对及三圈站点邻域，仅允许该对及其一圈邻点移动，约十个站点；外圈坐标逐位保持不变。检查所有受影响对偶单元及其邻居均有完整三角形扇，避免将尺度告警推到未测量的窗口外。拓扑保持不变。

原生实验从原始坐标自行求解，不读取 SciPy 算出的目标坐标。方法为有界切平面位移、有限差分、形状与活动角度约束投影及回溯；最多 80 次迭代，每次最多 16 次回溯，位移最多为典型边长的 15%。1.98 只是私有实验的停止目标，产品告警阈值仍为 2。

表中前后值均使用同一原生回放，从站点重建对偶角点；原值与冻结交付角点的统计存在浮点及经纬度转换差异，四例绝对差均小于 1e-4，未混用两种坐标的前后指标。

每个接受结果都重新通过原生 38.2°–81.8° 几何证书，所测对偶多边形无效计数为零。测量域内最大边长 CV、最大最长／最短边比、面积 CV 均未增加（数值容差 1e-10）；这不表示每个单元的全部指标均改善，也不是全网格质量统计。每次候选还检查尺度告警数不增加。

空允许移动集合返回原坐标；外部坐标逐位相同、拓扑不变、各站点半径保持的断言均通过。另将输入统一乘以 6,371,000 后重复，仍有三例消除该对告警、顶点 5 保留告警。证书适配器将输入归一化到单位球，缩放试验只验证该适配器和位移半径保持，不证明产品 Certificate 支持任意半径输入。

先前仅对形状指标投影的原生版本只消除了黑河告警，其余三例贴近硬角界后停滞。加入活动角度约束后得到上表。另有四份 SciPy 位移见证均通过原生几何回放并消除所选告警；它们说明存在几何可行位移，不能代替原生求解，更不能作为产品硬编码坐标。

## 2. 为什么没有直接接入生产构网

这些 fixture 来自最终交付网格，只有其站点、三角形、交付级别和索引；没有原始母网格的 `SourceLevelField`、事务 `source_vertex_slots` 或实际 `elastic_patch_for_state` 允许移动集合。因此尚未证明这些位移满足真实固定锚点、源需求和 remap 条件。

`requirement::row_required_level` 对全部正权重源重叠取最高要求等级。移动粗单元边界后，即使几何与面积尺度均改善，新增高要求源区域的正重叠仍可能使物理认证拒绝。不能用交付级别替代源需求。这里描述实现允许出现的失败形状，没有声称四份真实位移已经发生该失败。

仓库已有 `earthmesh_mesh::even_out_dual_cells`，其联合目标包括相邻面积平方根比。它目前用于非认证路径，没有 CMRC 任意固定点掩码、独立质量不退化或完整物理/remap 保护。现有 CLI 显式坐标更新还限制最多十个点、位移不超过边尺度的 3%、锚点固定及不跨级别面移动；本实验的 15% 位移预算不能冒充符合该入口。`certified.is_none()` 的路径隔离应保留；不能在发布尾部直接打开旧优化器，否则发布坐标会脱离认证坐标。

后续生产接入应优先复用现有优化器，在真实事务允许范围内试算，并完整复认证。还需覆盖跨高要求源区域的拒绝、非连续源槽映射、Whole／Window 和人工窗口截断等价，以及使用约 90 m MERIT 的质量、耗时与内存 A/B。本轮没有接入新优化器、放宽角界或质量阈值。

## 3. 已复现的可选更新退出漏洞

`build_mixed_certified_construction` 允许调用者提交可选局部坐标更新。旧实现仅在回调返回 `InvalidData` 时保留原网格；回调返回 `Ok(report)` 后，最终物理、remap 或几何认证失败会直接退出。

新增回归使用 42 个站点的真实母网格和全一级要求场。基线构网成功；回调合并一条边的两端却返回 `Ok(7)` 后，旧实现报错：`CMRC final-cell certification failed: Voronoi triangle 2 cannot be remapped`。T7920 修复前实际执行结果为 3 项通过、1 项失败，证明已认证原结果被可选试算的错误丢弃。

修复后先完整认证原网格并保留整套结果，再对私有副本调用回调和重新认证。候选需通过最终要求投影、Voronoi remap、几何证书，以及 `FinalCertificationEvidence::from_final_cells` 和 `finalize_geometry_certified_mother`；后两步覆盖 remap 残差、行数、指纹及组合证据，不能只生成 remap 统计就采用候选。任一步拒绝候选时返回原网格、证书、需求、remap 和 epoch／retry 报告，并在 `Control(reason)` 中保留原因。

回调主动返回 `InvalidData` 仍拒绝试算；其他回调错误原样传播。原网格认证失败仍报错，不借可选更新绕过硬门禁。没有回调时仍只执行原有一次最终认证并复用匹配的已认证 remap，没有新增网格克隆。

六项回归覆盖非法几何、回调拒绝及其他错误、no-op 接受、几何合法但固定地理需求不满足时的回退，以及真正移动一个非锚点后生成新 remap 并通过完整交付认证。物理拒绝用例是具有固定高要求栅格的真实小母网格：刚性旋转保持几何，但精细网格覆盖离开了需求区域。它验证公开回调 API 的认证边界，不宣称是符合 CLI 十点／3% 位移限制的真实优化请求。

可选回调路径会多做 control 认证、候选认证和交付检查中的网格克隆；普通构网路径不承担这项成本。本轮没有重复大型 MERIT 性能 A/B，也没有发布新版本。
