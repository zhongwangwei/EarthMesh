# 40°–80° 角度窗口：两项实验的度量契约

日期：2026-08-14
状态：规格，未实施
背景：指南 §11.65（当前局部算子族的平台）

这份文档存在的唯一理由，是让两项实验产出**可以互相比较、也可以和基线比较**的数字。
本轮之前已经出现过三次"看起来精确、实际不可比"的量：把平面关系当球面恒等式、把全局
`cov/δ` 用在变分辨率点集上、把 `h` 当成点距。定义先锁死，再动手。

---

## 1. 两项实验，各自能答什么

| | Frontal 原型 | 离线 feasibility oracle |
|---|---|---|
| 位置 | HARP 内，细化过程中 | HARP 外，独立 Python |
| 输入尺寸场 | 现有判据的生成期目标尺度（**未经梯度限制**） | 基线导出的**冻结（已梯度限制）**场 |
| 三角化 | HARP 自己的增量 Delaunay | `scipy.spatial.ConvexHull` |
| 能答 | 需求驱动调度下换放点规则的收益 | 该冻结场下是否**存在**满足窗口的点集 |
| **不能答** | Frontal-Delaunay 作为已发表方法的效果 | HARP 的物理需求语义、12 个基础五边形的身份、SiteId 稳定、增量细化、事务接入 |

（度数**可以**从凸包直接统计，所以 §6.1 把 `max_degree ≤ 7` 和 `degree < 5` 列为 Go 门是
成立的；从冻结 CSV 答不了的是判据语义与五边形身份。）

**两者共享评价代码，不共享输入尺寸场。**`target_cell_scales()` 在细化结束、质量优化开始时才
构造，Frontal 原型发生在细化过程中，用不了这个"还不存在"的场。因此**不能做逐候选 A/B**，
只能各自与同一基线比较。

## 2. 锁定的度量定义

### 2.1 角度：两种都输出

| 名称 | 定义 | 地位 |
|---|---|---|
| **球面角** | 在顶点切平面内投影两条测地线方向后取夹角（`criteria::triangle_angles_deg` 的做法） | **判据以此为准** |
| **平面比较角** | 由三条弦长经余弦定理得到 | 代理，与 `ρ` 自洽 |

每次实验**两者都输出**，并报 `|球面 − 平面|` 的中位/p99/max。

**偏差随单元尺度平方增长，所以必须按 fixture 报，不能引用别的 fixture 的数字。**

| fixture | 顶点数 | 逐角偏差中位 | p99 | **max** |
|---|---:|---:|---:|---:|
| NXP81 生产基线（299,442 三角形） | 149,723 | 4.44e-4° | 1.97e-3° | **4.32e-3°** |
| **NXP6 代理（934 三角形）** | **469** | **3.23e-1°** | 3.79e-1° | **3.79e-1°** |

NXP81 上球面角和 − 180° 的中位是 1.23e-3°、max 1.24e-2°；窗口外角数球面 220,350 对平面
220,347，差 3。

**在 NXP6 上平面代理带约 0.4° 的误差**，比 NXP81 大两个量级（边长约 30 倍，盈余按平方走）。
这不可忽略：我们正在用单位为"度"的余量讨论窗口。**所有 NXP6 上的角度结论必须用球面角，
`ρ` 只作辅助。** 平面量是代理不是恒等式，且代理精度依 fixture 而变。

### 2.2 逐三角形半径-边比

`ρ = R / e_min`，由**弦长**构造（平面比较三角形）。对该比较三角形
`θ_min = arcsin(1/(2ρ))` 精确成立；对球面网格是代理，偏差同 2.1。

等边基准 `ρ = 1/√3 = 0.57735`。`θ_min ≥ 40° ⟺ ρ ≤ 0.77786`。

### 2.3 `δ` 的约定（二倍陷阱）

**本文档一律使用 `δ` = 完整最小点距**（不是 separation radius）。

| 约定 | 六边形格的值 |
|---|---|
| `γ = cov / δ`（**本文档**） | 0.57735 |
| `cov / (δ/2)`（部分文献） | 1.15470 |

引用任何外部数值前必须先确认对方用的是哪一个，**差一倍**。

### 2.4 目标边长与归一化

HARP 的 `h` 是**等面积圆半径**，不是点距：`h = sqrt(A_voronoi / π)`。目标边长是

```
ℓ*(x) = CELL_SCALE_TO_EDGE_LENGTH · h(x) = 1.90462561372791472 · h(x)
```

（由正六边形胞 `A = (√3/2)ℓ²` 得 `h = ℓ·sqrt(√3/(2π))`，故 `ℓ = h·sqrt(2π/√3)`。）

归一化指标：

```
q_sep       = min over edges (i,j) of   d_ij / ((ℓ*_i + ℓ*_j)/2)
q_cov_est   = sup over x of   ( min_i d(x, x_i) ) / ℓ*(x)
```

规则三角格：`q_sep = 1`，`q_cov = 0.57735`。

**这两个量只作点集诊断，不导出角度保证。** 曾经写过
`θ_min ≥ arcsin(q_sep / (2 q_cov))`，那是错的：`ρ = R/e_min` 展开后是

```
rho  <=  (q_cov / q_sep) * [ l*(circumcentre) / ((l*_i + l*_j)/2) ]
```

中括号那一项在均匀场下等于 1、在变密度场下不等于 1——`q_cov` 在外心处用 `ℓ*(x)` 归一，
`q_sep` 在边两端用平均 `ℓ*` 归一，两者不能直接相除。**角度结论一律以直接测量的球面角
和逐三角形 `ρ`（§2.2）为准。**

**不得使用全局 `cov/δ`**：变分辨率下全局 `δ` 由最细区决定、全局 `cov` 由最粗区决定，
即使每个邻域完美，全局比值也可能很差。

### 2.5 `q_cov_estimate` 的协议

极大值**不保证**落在 Voronoi 顶点——变尺寸场下分母也在变，极值可以出现在 `ℓ*` 下降快于
`d` 的过渡处。协议：

1. Fibonacci 球面均匀采样，采样间距 `s ≤ ℓ*_min / 10`；
2. 取比值最高的 top-k（k = 256）；
3. 每个种子做局部球面极大化；
4. **用两档采样密度（`s` 与 `s/2`）验证收敛**；两档不一致则改用按 `ℓ*(x)^{-2}` 分层采样；
5. 报告名保留 `q_cov_estimate`，**不得去掉 estimate**。

NXP6 的量级：`ℓ*_min = 1.9046 × 2.0319e5 = 3.870e5 m`，球面积 `4πR² = 5.101e14 m²`，
`s = ℓ*_min/10` 需 `≈ 3.4e5` 个采样点，第二档 `1.4e6`。可忽略成本。

## 3. 冻结场数据契约

由 `cycle/tests.rs::export_the_frozen_target_scale_field`（`#[ignore]`）导出：

```
# sphere_radius_m=... background_scale_m=... gradient=0.3
# cell_scale_to_edge_length=1.90462561372791472e0
site_id,x,y,z,target_cell_scale_m
```

`x,y,z` 是**该值被计算时**的位置。站点随后会移动，而值按 SiteId 保留；拿优化后的位置配
旧值等于把整个场搬运一遍。

NXP6 基线导出：469 行，`radius = 6.371229e6 m`，`background = 6.710320e5 m`，
场跨度 `2.031884e5 … 6.710320e5`（3.303 倍），导出时窗口外角 282。

**读取规则**：离线端对该点云做只读空间插值得到 `h(x)`，再乘 `1.9046256` 得 `ℓ*(x)`。
**不得改调 `TargetScale::target_scale_m_at()`**——它返回的是**未经梯度限制**的原始判据值，
而梯度限制是 `target_cell_scales` 在 `active_triangle_slots` 收集的边上做的队列松弛，
离开那张网格图无法复现。用原始值会得到更陡的场，实验作废。

**由此产生的解读限制**：该场的梯度限制绑定在一张特定网格图上。基于它得到的结论是
**关于这个场的**，不是关于产生它的那组判据的。

## 4. 三角化的正确性前提（离线端）

单位球面点集的三维凸包面对应球面 Delaunay 三角形，**前提要逐条验**：

```
qhull_options='Qt'        # SciPy 本来就默认带 Qt，显式写只是留痕，不是必需
禁止 'QJ'                 # 随机扰动同时毁掉确定性与真实质量；退化直接报告
```

度量之前必须通过：

| 检查 | 说明 |
|---|---|
| `len(hull.vertices) == V` | 任何未严格落在球面上的点会被判为内点而**被丢弃** |
| `F == 2V − 4` | 由 `3F = 2E` 与 `V−E+F=2` 得；合并面片会让 F 偏小 |
| `E == 3V − 6` | 同上 |
| 每条边恰属两个三角形 | 流形性 |
| 所有面朝向一致 | 与 EarthMesh 的 `orientation_on_sphere` 同口径 |
| 无零面积面片 | 叉积模长阈值；`Qt` 也挡不住共球退化 |
| 原点严格在凸包内 | 否则不是球面三角化 |

无重复/近重复点：先按 `min pairwise distance > 0` 断言。

## 5. 点数标定回路

`h(x) → N` 没有解析关系（文献做法是预先制表再反查）。**比较前必须把点数标定到基线 ±10%**：
整体缩放场 × 因子，重生成，迭代至 N 落进区间。

否则会出现"多生成 35% 的点，角度当然更好"这类不可比结果。

## 6. Go / No-Go

### 6.1 离线 oracle

全部满足才算 Go：

```
球面 min_angle              >= 40°
球面 max_angle              <= 80°
max_degree                  <= 7
degree < 5 的顶点数          == 0
尺度违例数                   == 0        （邻接胞尺度比，点集 + 冻结场即可算）
顶点数                      在基线 ±10% 内
```

**物理需求不列入 oracle 的 Go 门**：oracle 复现不了完整的 HARP 判据语义（§1），所以它对该项
只能报 **未评估**，不能报 0。HARP 内的原型继续把它作为硬门——那是它能答而 oracle 不能答的
部分，两边不要互相冒充。

### 6.2 Frontal 原型（NXP6，基线 65 个越界角）

```
Go    ：最终 ≤ 32   且  顶点增长 ≤ +10%   且  违规站点数同比例下降
No-Go ：未减半，或物理/尺度/拓扑退化
```

顶点增长必须一并约束——**用更多单元换更少违规永远做得到**，不归一化的话残留门槛可以被
无意义地满足。"改善来自多处"用**承载违规的不同站点数**衡量，不只看角数。

## 7. 结果解读规则

| 结果 | 能推出 | **不能**推出 |
|---|---|---|
| oracle Go | **该冻结场**下存在可行点集 | 判据本身可满足；HARP 能到达它；需求/度数/谱系（除非单独测了） |
| oracle No-Go | 否定**这一个实现与这组参数** | 否定 meshfree / Riesz 谱系 |
| oracle min 达标、max 不达标 | 点集分布改善有效，上半边需另加机制 | 必须采用 VanderZee（那只是候选之一） |
| Frontal No-Go | 否定**需求驱动调度下的**前沿放点 | 否定已发表的 Frontal-Delaunay |

## 8. 约束

1. **不新增第三套 h field。** 只加一个测试专用的冻结场导出 + 离线只读插值层。
2. 两条路线都**不得依赖 `earthmesh_hfield`**（那是 Method-C / Red-Green 的栅格场）。
3. oracle **留在 Rust 之外**：仓库里没有任意点集的球面 Delaunay
   （`MeshState::from_parts` 要求调用者自带拓扑），不为一次性实验新写一个。
4. oracle 一期只做**无边界、未 ocean-carve 的闭合球面**；区域边界另算。
   NXP6 fixture 天然满足（`from_icosahedron` + `TargetScale`，无受保护段）。
5. 外部数值引用前先核 `δ` 的二倍约定（§2.3）。
6. 任何"恒等"表述前先核球面/平面口径（§2.1）。
