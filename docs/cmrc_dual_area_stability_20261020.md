# CMRC 后续：小球面面积精度与既有优化器复用（2026-10-20）

本轮继续使用原生约 90 m MERIT。生产改动仅修复既有 dual-shape 优化器的小球面三角形面积计算，并等价简化一处 HField 坐标校验以通过 Rust 1.95 的严格 Clippy；没有接入默认 CMRC 优化器、调整质量门槛或发布新版本。

## 已复现的面积精度问题

`earthmesh_mesh::mesh_dual_shape::triangle_area` 原分子为 `abs(a·(b×c))`。在单位球上表示约 90 m 的小三角形时，直接叉积相近坐标会发生消减，结果随所在经纬度出现数值偏差。回归构造两条 90 m 正交球面边，独立解析面积为 `2 atan2(sin²(t), (1+cos(t))²)`，其中 `t=90/6371000`，并测试四个方向。

T7920 修复前的回归真实失败：东经 100°、北纬 38° 处相对误差为 `2.449e-8`，超出 `1e-10` 的回归容差。修复将分子改为等价的 `abs(a·((b−a)×(c−a)))`，复用已有减法、点积和叉积；分母、面积分支、公开接口、优化目标及调用路径保持原样。解析回归和既有闭合球／局部扇形形状测试均通过。

该函数只服务既有 dual-shape 计算；直接调用来自非认证 CLI 路径和 MethodC LEPP。认证 CMRC 的 `certified.is_none()` 隔离继续保留。这个数值误差远小于历史约 2.02–2.15 的相邻尺度比偏差，不能据此声称修复了质量软告警。

HField 的改动只是将 `!(finite_lon && finite_lat) || !in_range` 合并为 `!(finite_lon && finite_lat && in_range)`。有限性、范围和短路行为一致；没有修改 HField 面积公式。第一轮 589 项相关测试通过，但严格 Clippy 被此原有布尔表达式拦住，因此该作业整体记为失败，不能将测试通过当作作业成功。

## 私有真实源需求试验的边界

试验复用仓库已有 `even_out_dual_cells`，只在私有构网快照中增加逐点移动掩码和认证适配，不提交新求解器或公共 API。先完整认证 control；从实际最差相邻尺度对及一圈邻点中最多选 10 个可移动点，原区域外缘、来源地址确认的二十面体顶点及原 covered-target 集合 R 之外保持固定。可移动点及其所有受影响对偶邻点必须位于 R。没有删除固定单元或只统计可动点。

既有优化器保持原目标和两阶段遍历，每阶段最多一轮。候选归一化后位移上限为当地边尺度的 3%，最多四次有界回溯；先检查完整测量域通过既有 `guarded_metric_regressions` 门禁，再从原始 fine 母网格生成新 remap，严格保持原 R。使用原始 `SourceLevelField` 在重编号之前认证，再执行实际 Raster 或 Lattice 分支、原 Euler／边界／角界几何认证、published 重编号 remap 证据以及 `finalize_region_geometry`。全部通过后才替换候选，否则保留 control，并断言固定坐标逐位、拓扑和报告／计数不变。

`complete_final_certification=true` 只表示最终保留的 control 或 candidate 完整认证，必须结合 `decision` 和拒绝阶段读取。实际数据验收对任何缺失认证、固定点或计数证明都报错；若保留 control，还对两份最终 NetCDF 做类型、维度、属性、掩码和值的严格比较。前后核对 MERIT 两个图幅、LANDTYPE 和同一可执行文件的 SHA256。

这验证区域最终构网结果的源需求保护；并未证明此前各组件事务的 `elastic_patch_for_state` 允许集合，也不能代替 Whole／Window 等价和更广泛的生产集成回归。原生 DEM 约 90 m，`finest_m=90` 经既有层级选择后实际最细名义尺度仍为约 125.005 m。

测量范围须区分：探针检查完整区域的 682,873 个闭合对偶单元，其中原认证覆盖 R 为 682,264；最终发布域为 635,769。完整区域最大相邻尺度比从 **2.03982899 降到 2.03306354**，告警仍是 **4→4 对**。既有优化器未限制位移的内部提议曾显示 4→3 对，但它未满足本试验 3% 位移上限，不能作为采用结果；最终只采用了经过限幅和完整认证的六点候选。

通过现有质量保护策略不表示每项原始指标都逐项下降。例如完整区域跨级别面积 CV 从 3.524207316547499 微增至 3.524207330515238（约 1.40e-8）；候选通过的是既有 guarded 策略，发布域面积 CV 保持上表数值。

严格 NetCDF 后处理比较确认：最终 `gridfile_NXP8006_hex_landmesh.nc4` 的类型、维度、全部属性、掩码和值均无差异；`regional_parent` 仅 `GLATM`、`GLATW`、`GLONM`、`GLONW` 四个坐标变量不同。两份发布域质量报告除 `mesh_name` 输出路径外完全相同。因此本次证明了真实源需求下的非零位移可行，**没有改善最终发布质量**。

本次单组顺序 A/B 的总耗时增加 61.529 s（约 26.7%），探针自身记录约 59.5 s；RSS 均约 3.32 GiB，这次测量不支持内存改善结论。共享机器上的单次观测不是统计性能基准。由于发布域质量没有收益，本轮保留私有试验，不接入默认 CMRC。

后续若继续优化，应从最终发布域的实际告警对选取候选，并验证真实组件的允许移动集合、Whole／Window 等价及多例成本；本轮没有以完整区域指标替代发布域收益，也没有放宽角界或质量门槛。历史四组全量网格的软告警仍按前述记录保留。
