# EarthMesh 深度缺陷审计（2026-10-26）

**审计对象**：`codex/cmrc-local-quality-20261020` @ `5e86d7b9`（= origin；最近一次 CI 全绿代码提交 `89ea8277`，其后 3 个提交只改文档）。基线发布 `refs/tags/v3.0.0-alpha11`（tag 对象 `26bed497`，树等于 `1a4cd1a8`）。

**范围**：根 Rust workspace 的 17 个 crate、独立的 `gui-tauri/src-tauri` workspace、Python 打包与 scripts、Makefile / CI 门禁、以及 `docs/mesh_construction_technical_guide.md` §11 记录的已知缺陷复核。本分支相对 alpha11 的代码改动全部集中在：`earthmesh_refine_certified/src/construction/mod.rs`（`finalize` 闭包 + 可选局部更新回退，指南 §11.153）、`component_transaction.rs`（仅测试）、`tests/local_update_transaction.rs`（新增）、`earthmesh_quality`（gate `detail`、worst-cell GeoJSON 字段）、`earthmesh_mesh/mesh_dual_shape`（球面面积公式）、`earthmesh_hfield`（布尔等价改写）。

**方法**：1 个主审 + 6 个并行独立审计线程（事务/定稿、核心引擎数值与诊断、细化后端、CLI/NetCDF/打包、GUI/Tauri、门禁与忽略测试），全部只读；候选缺陷要求“可复现命令 + 输出”或“严格代码路径证明”，否则降级为风险/未验证。证据在 `.omx/artifacts/bug-audit-20261026/`（6 份分报告 + 门禁日志 + 忽略测试清单）。

## 结论摘要

- **未发现 Critical / High 缺陷**；未发现会让网格“合法、通过质量检查、但不是被请求结果”的新静默失败（指南 §11.1 类）。
- **本分支近期的 CMRC 定稿改动经逐路径核对是正确的**：无回调节点的普通路径与 alpha11 逐字等价；被保留的 control 在候选失败后与重新构建的 control 完全一致（网格/证书/remap/需求/epoch/计数）；回调输入网格与旧路径相同（`certify_geometry_with_contract` 保身份）；面积公式是数学恒等变换且精度显著改善（90 m 三角形相对误差 2.45e-8 → 2.75e-12），新测试对旧公式确实会失败，不是同义反复。
- **确认 2 项 Medium**：① GUI 丢弃新增的 `quality_summary.json` `gates[].detail`（信息丢失，不影响判定值）；② 可选 CMRC 局部更新（`EARTHMESH_CMRC_LOCAL_UPDATE`）的交付物没有 provenance 绑定（请求/基准文件路径与内容哈希都不入库，且 apply 时重新读取；属审计追溯风险，不是已复现的错误网格）。
- **其余约 20 项为 Low/Info**：多数是历史上就存在的诊断/防御/文档/元数据卫生问题，或仅 API 可达、当前生产路径不可达。已逐项给出行号、机制、影响与修法。
- **CI 覆盖面本身有两处值得补**：没有任何 CI 任务构建 Tauri bundle；`check_gui_js` 以源码子串断言为主，正好漏掉这次发现的 GUI 端 schema 漂移。
- 文档里记录的历史缺陷（Method-C id 空间、§11.30 单位错配、AUDIT_REPORT 的 M-1/M-2/L-1、RedGreen 3 级质量等）已逐条复核：**多数已修或随 HARP-DV 退役而消失**，没有发现“文档说已修但代码没修”的情况。
- **2026-10-26 后续分四批已落地 17 项修复**（第一批 A1/A3/A4/A5/A8/A9/A22，commit `919ec6d5`；第二批 A2/A7/A12/A13，commit `2c2f33b8`；第三批 A10/A11/A14，commit `7e91d955`；第四批 A6/A19/A20，commit `593ad3e9` + 本轮 GUI 提交），每项都含新回归测试/定向验证与对应门禁复跑，详见第六节；其余需要方案判断的条目保持原状。此外，审计结束后并行 Codex 会话发现并修复了 1 项本报告未覆盖的“失败报告计数字段”缺陷（A25，commit `1c82f60f`，已独立复核，见第六节末）。

## 四、已知但非本次新增的结构性限制（不建议当 bug 修）

以下均在 `docs/` 有记录，属有意取舍或产品决策，本次审计确认仍然存在：

1. **CMRC 局部更新优化器未接入生产**（环境变量 opt-in）。真实约 90 m MERIT 单例已证明可提交并交付，但：注入后晚期失败/回滚未做真实数据回归；只验证了单例，黑河 4 级/二十面体顶点等多例成本未验证；`Window` 紧凑工作区等价性仍为 false（实际走 Window→Whole 回退）；真实 90 m 案例仍有 3 对相邻尺度软告警；单例耗时 +39.8%。这些是“未完成的工作”，不是已定性 bug。
